# Wanderly — tourism site

A one-page travel & tours website: plain HTML, CSS and a little JavaScript, with no build step.

## Run it

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Structure

- `index.html` — all page sections (hero, destinations, about, popular, gallery, guides, testimonials, promo, blog, footer)
- `assets/css/style.css` — styles; colours and fonts are set as variables at the top (`:root`)
- `assets/js/main.js` — sticky header, mobile menu, destination slider, scroll animations, counter
- `assets/img/` — photos

## Customising

- **Brand name:** search for `Wanderly` in `index.html`.
- **Colours:** change `--accent` and `--bg` in `style.css`.
- **Fonts:** Bebas Neue, Inter and Yellowtail from Google Fonts.
